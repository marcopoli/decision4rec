# Additional Materials

Supplementary material of the paper *Decision4Rec: A Jev-Inspired Framework of Decision Models on Knowledge and Active Graphs for Multi-Agent Recommender Systems*. The paper cites these files as AM1 to AM11. All numbers are on the development users of the paper (2,000 test and 1,000 validation users per domain), unless a file says otherwise.

| File | Content |
|---|---|
| [AM1_runtime.md](AM1_runtime.md) | The event-sourced runtime: events, behaviors, counterfactuals, and its status |
| [AM2_item_content.md](AM2_item_content.md) | How much item content the decision model reads at 90 and 250 characters |
| [AM3_fused_score_weights.md](AM3_fused_score_weights.md) | The five settings of the weights of the fused candidate score |
| [AM4_baselines.md](AM4_baselines.md) | Training of the baselines: protocol, grids, PrepRec |
| [AM5_perspective_agents.md](AM5_perspective_agents.md) | The perspective agents: all versions and results |
| [AM6_overlap.md](AM6_overlap.md) | How far the decision model repeats the ranker, with training variants and 250 characters per item |
| [AM7_jev.md](AM7_jev.md) | Jev and Kev after fusion, the API compared with open weights, repeatability of the hosted answers |
| [AM8_explanations.md](AM8_explanations.md) | Explanations by removing one family of statements |
| [AM9_ongoing_work.md](AM9_ongoing_work.md) | Status of the ongoing experiments |
| [AM10_metrics.md](AM10_metrics.md) | HR@10 and MRR@30 next to NDCG@10 for the main systems |
| [AM11_claim_tests.md](AM11_claim_tests.md) | The tests behind the explanations given in the paper, with the scripts that produce them |
